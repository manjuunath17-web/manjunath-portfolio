MANJUNATH PORTFOLIO WEBSITE

Files:
- index.html: page structure and content
- style.css: responsive styling, including the updated video gallery
- assets/: images extracted from the supplied PDF

Preview locally:
1. Keep index.html, style.css and the assets folder together.
2. Add your own video files into assets using these exact names:
   - waterfall.mp4
   - misty-cliff.mp4
   - sunset-sea.mp4
3. Double-click index.html to open it in your browser.

The supplied PDF did not contain the original video files, so you must add the three MP4 files yourself.
For GitHub Pages, upload the contents of this folder to the root of your repository.
